# Антислоп / antislop-shield

Редакторский навык для работы с русским и английским нейрослопом. Он проверяет структуру, ритм и языковые маркеры, помогает переписать текст без потери фактов и голоса автора и не считает оценку AI-детектора доказательством авторства.

В сборке четыре режима: **аудит**, **переписывание**, **превентивная генерация** и **пересборка** текста из проверенных фактов. Режим выбирается по задаче; порядок работы и ограничения описаны в [SKILL.md](SKILL.md).

## Состав

- [SKILL.md](SKILL.md) — протокол навыка.
- [INSTALL.md](INSTALL.md) — установка и вызов.
- [references/](references/) — структурная проверка, словари маркеров, рубрика, приёмы правки и справка о детекторах.
- [assets/prompt-templates.md](assets/prompt-templates.md) — шаблоны запросов.
- [scripts/slop_scan.py](scripts/slop_scan.py) — автономный сканер на Python 3 без сторонних зависимостей.

Пример запуска сканера:

```bash
python3 scripts/slop_scan.py текст.md
python3 scripts/slop_scan.py текст.md --exclude-quoted
```

Сканер показывает эвристические находки для редактора, а не определяет, кто написал текст. Правка должна сохранять проверяемые факты, жанр и авторскую позицию.

Источники отдельных приёмов и исследований перечислены в справочных файлах. Лицензия на содержимое сборки не заявлена.
